# Capstone-Project

JDSS is a human-in-the-loop research prototype for case triage and precedent search across the IPC-to-BNS transition. Its priority score is a deterministic policy heuristic; it is not a validated prediction of legal urgency or listing outcomes. Precedent retrieval now uses a bounded LangGraph planner with allow-listed statute expansion and retrieval actions; the ordinal relevance grades are uncalibrated. The scheduling simulator is an illustrative scenario analysis using assumed capacities and bootstrap case profiles. The retrieval benchmark currently reports ranking overlap and limited section-hit proxies without human relevance judgments; it does not establish NDCG/Recall performance or statistical significance. See [RESEARCH_PAPER_DRAFT.md](RESEARCH_PAPER_DRAFT.md) for evaluation scope and limitations.
